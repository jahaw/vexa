# learn-docs

Vexa 对外 API 能力的学习与整理资料（非官方文档，按源码与 `architecture.calm.json` / `contracts.seal.json` 归纳，仅供内部学习参考）。

## 目录

| 文件 | 语言 | 内容 |
|------|------|------|
| `API_DOCS.md` | 中文 | 按模块（Agent、Meeting、Bot、Transcript、Recording、WebSocket、MCP 等）整理的对外接口、请求方式、参数说明与典型使用场景 |
| `API_INTERFACES.md` | English | Catalog of all outward-facing APIs and published versioned contracts (HTTP / WebSocket / RPC) |
| `API_INTERFACE_CN.md` | 中文 | `API_INTERFACES.md` 的中文版：服务级接口说明与版本化数据契约规范 |

> 权威接口定义以源码与官方文档（https://docs.vexa.ai）为准；本目录内容不随版本发布流程校验，可能滞后于代码。
